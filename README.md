## Featured Project

### Sales KPI Automation & Performance Reporting

A portfolio project demonstrating an end-to-end sales reporting workflow built with Python, Excel, and Power BI.

**What the solution does:**
- Cleans and validates sales data before processing.
- Detects critical data issues and prevents unreliable reporting.
- Calculates sales and performance KPIs.
- Generates structured Excel reports.
- Provides an interactive Power BI management dashboard.
- Organizes local processing, audit outputs, delivery files, archives, and execution logs.

The project uses demonstration data and showcases a repeatable reporting workflow. Power BI dashboard refresh is managed separately from the local automation process.
